## Getting Started

1. Ensure you have completed the chapter reading
2. Have your workspace set up:
   ```bash
   cd ~/humanoid_ros2_ws
   source install/setup.bash
   ```
3. Create a branch for your exercises:
   ```bash
   git checkout -b exercises/module1
   ```
